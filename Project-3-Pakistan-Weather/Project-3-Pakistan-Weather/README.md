# Project 3 - Pakistan Weather Visualization

## 📌 Project Overview

This project uses Python and Matplotlib to visualize weather data for selected cities in Pakistan.

The project explores different weather variables using multiple visualization techniques.

## 🛠️ Technologies Used

- Python
- Matplotlib

## 📊 Visualizations

The project includes different charts to visualize weather information, such as:

- Temperature comparison
- Rainfall comparison
- Humidity comparison
- Weather trends
- Scatter plots for relationships between weather variables

## 🎯 Concepts Practiced

- Bar charts
- Line charts
- Scatter plots
- Figure and Axes
- Subplots
- Chart customization
- Grid
- Labels and titles
- Tick rotation
- Layout adjustment
- Saving figures

## 💡 Key Learning

Through this project, I learned how to visualize weather-related data and select different chart types according to the analytical question.

## 🔍 Key Observations

The visualizations provide different views of weather conditions across selected Pakistani cities.

> Note: This project uses a practice dataset created for learning purposes and should not be treated as real-time weather information.
