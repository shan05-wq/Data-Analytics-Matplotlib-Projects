# Project 5 - World Data Visualization

## 📌 Project Overview

This project uses Python and Matplotlib to visualize and explore selected world data.

The project compares population, GDP, life expectancy, and internet usage across selected countries.

It also explores relationships between GDP and other variables using scatter plots.

## 🛠️ Technologies Used

- Python
- Matplotlib

## 📊 Visualizations

The project includes:

- Population Bar Chart
- GDP Horizontal Bar Chart
- Life Expectancy Chart
- Internet Usage Bar Chart
- GDP vs Life Expectancy Scatter Plot
- GDP vs Internet Usage Scatter Plot
- Complete World Data Dashboard

## 🎯 Concepts Practiced

## 📈 Analysis

### Population

A bar chart is used to compare population across the selected countries.

### GDP

A horizontal bar chart is used to compare GDP values across countries.

### Life Expectancy

A line chart is used to visualize differences in life expectancy across the selected countries.

### Internet Usage

A bar chart is used to compare internet usage percentages.

### GDP vs Life Expectancy

A scatter plot is used to explore the relationship between GDP and life expectancy.

### GDP vs Internet Usage

A scatter plot is used to explore the relationship between GDP and internet usage.

## 💡 Key Learning

This project helped me practice combining multiple visualization techniques into a single data analysis project.

I also learned how annotations can be used to identify individual observations in scatter plots.

> Note: The dataset is a practice dataset created for learning purposes. The values should not be treated as current official statistics.
