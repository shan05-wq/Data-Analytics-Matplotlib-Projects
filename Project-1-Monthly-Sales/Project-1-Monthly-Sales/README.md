# Project 1 - Monthly Sales Visualization

## 📌 Project Overview

This project uses Python and Matplotlib to visualize monthly sales data through different types of charts.

The same dataset is visualized using a line chart, bar chart, and scatter plot to understand how different visualizations can communicate data.

## 🛠️ Technologies Used

- Python
- Matplotlib

## 📊 Visualizations

### 1. Line Chart
Used to visualize the sales trend across the months.

### 2. Bar Chart
Used to compare sales between different months.

### 3. Scatter Plot
Used to display individual monthly sales values.

## 🎯 Concepts Practiced

- `plt.plot()`
- `plt.bar()`
- `plt.scatter()`
- Figure size
- Titles and labels
- Legends
- Grid
- Markers
- Line width
- Layout adjustment
- Saving figures with `savefig()`
- High-resolution charts using `dpi`

## 💡 Key Learning

I learned how the same dataset can be represented using different visualization techniques depending on the analytical purpose.
