# Project 2 - Student Performance Analysis

## 📌 Project Overview

This project uses Python and Matplotlib to analyze and visualize student performance across different subjects.

The project calculates the overall average marks of students and presents the results using multiple types of visualizations.

## 🛠️ Technologies Used

- Python
- Matplotlib

## 📊 Visualizations

The project includes:

- Bar Chart
- Histogram
- Scatter Plot
- Pie Chart
- Combined Dashboard

## 📈 Analysis

### Bar Chart

Shows the average marks for Mathematics, English, and Computer Science.

### Histogram

Shows the distribution of students' overall average marks.

### Scatter Plot

Shows the relationship between Mathematics and Computer Science marks.

### Pie Chart

Shows the distribution of students across different grades.

### Dashboard

Combines multiple visualizations into a single figure using Matplotlib subplots.
